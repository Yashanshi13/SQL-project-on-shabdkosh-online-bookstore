# SQL-project-on-shabdkosh-online-bookstore
This project is part of my SQL learning journey, where I analyzed sales and inventory data for an online bookstore — Shabdkosh.
The goal was to use SQL queries to uncover insights about book sales, customer behavior, and stock management.

Project Overview

The Shabdkosh Online Bookstore project focuses on analyzing sales data to answer key business questions such as:
Which genres perform best?
Who are the top customers?
How much stock remains after fulfilling orders?
This analysis helps the bookstore make better inventory and marketing decisions.

Dataset Overview

The project is based on three main tables:

Books
Book_ID — Unique identifier for each book
Title — Book title
Author — Book author
Genre — Book category
Published_Year — Year of publication
Price — Selling price
Stock — Available stock

Customers
Customer_ID — Unique customer ID
Name — Customer name
City — Customer location

Orders
Order_ID — Unique order ID
Customer_ID — Who placed the order
Book_ID — Which book was ordered
Quantity — Quantity ordered
Order_Date — Date of the order

Problem Statements

Below are the main analytical SQL tasks performed:
Retrieve the total number of books sold for each genre.
Find the average price of books in the Fantasy genre.
List customers who placed at least two orders.
Identify the most frequently ordered book.
Show the top 3 most expensive Fantasy books.
Retrieve the total quantity sold by each author.
List cities of customers who spent over $30.
Find the customer who spent the most.
Calculate stock remaining after fulfilling all orders.

Highlights

Used SQL commands like JOIN, GROUP BY, ORDER BY, LIMIT, and AGGREGATE FUNCTIONS
Focused on real-world sales insights
Designed clean and modular queries for easy readability
Built using SQL Workbench
